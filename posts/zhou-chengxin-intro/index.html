个人介绍

我是周成昕，华中科技大学工学学士。长期在 Linux 环境下学习 C++ 与后端系统，关注高性能服务、网络编程、缓存与存储。习惯从源码和实测出发：先读实现、再写最小复现、最后用数据验证结论，而不是停在“看起来对”。

在个人项目 seckill-cpp 中，用 C++ / Drogon 从零实现了一套高并发秒杀系统：从 MySQL 直连、原子扣减与幂等下单，到 Redis 缓存、布隆过滤器、本地 LRU 多级缓存与在途闸门；用 JMeter 记录每一步基线（直连 QPS≈440、缓存后 list 10557 / detail 8024、命中率 83.8%），并把路线图和取舍写进仓库文档。

在开源方面，读 Drogon RealIpResolver 源码时发现它只支持 IPv4，提 issue #2596 并完成 PR #2598（3 文件、+255/−36，测试 5→14），由项目作者合并。这段经历后来写成《给 Drogon 提第一个 PR》，重点复盘“读源码得出的结论”和“能进上游的 patch”之间的取证纪律。

同时持续在个人博客（RSS 可订阅）输出 800+ 篇技术文章，覆盖 CS 基础（CS50 / 61A / 61B / CSAPP / OS）、系统与工程、C++ / Linux / 网络 / 数据库、AI 观察。写作让我把零散经验整理成可复用的判断，也让我保持对新技术的好奇。
