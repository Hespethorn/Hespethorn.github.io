AI 新闻速递｜2026-08-18：Agent 运行时开源、AI 反向维护开源库、视频预训练跨形态、机器人进养老院

Created2026-08-18|AI-News
|Word Count:2.6k|Reading Time:8mins

昨天的主题是"开源登顶、安全反噬、插件互通、全身协同、原生全模态"(GLM-5.3、Ghostjacking、Agent Plugins、北大灵巧手、智元 WITA-Omni)。今天两条线继续拐弯:AI 编程从"用现成工具"拐进"底层运行时开源 + AI 自己维护开源库 + 大厂内部工具开源化",具身智能从"全身协同/全模态"拐进"纯人类视频跨形态预训练 + 真实照护场景落地"。挑了 5 条,每条附上为什么值得关注。

1. DeepSeek 开源 Harness v0.1:Agent 运行时本体 MIT 放出,插件架构可换模型/工具/UI

事件:8 月中旬,DeepSeek 将内部自用的编码 Agent 运行时 Harness v0.1 以 MIT 协议公开发布,任何人可免费商用与修改。它的核心是一套名为 Cordis 的插件架构——开发者能不动"连接各部件的胶水代码",直接替换底层模型、工具、文件系统访问、用户界面任一环节;兼容 DeepSeek、Anthropic、OpenAI、Google、Azure 等多家模型。MIT 协议去掉了同类框架常见的法律与商用壁垒,且主打"生产可用"而非玩具 Demo。

为什么值得关注:这把昨天"Agent Plugins 跨工具互通"的叙事又往下挖了一层——现在连 Agent 的"发动机"都开源了。过去团队做自主编码 Agent,要么买闭源平台、要么从零搭"模型连真实任务"的脚手架;Harness 把 DeepSeek 自己跑基准测试验证过的运行时直接交出,等于把"造 Agent 的门槛"从"写一套基础设施"降到"拼装插件"。更深的信号:编码智能体的竞争重心继续从模型层沉降到运行时与编排层,而这一层正在被开源快速填平。下一步看 Cordis 生态的插件丰度,以及各家能否基于它长出差异化。

2. Vercel 用"Agent 工厂"养开源库:4 周贡献 35% 已合并 PR、关掉 70% 七月问题

事件:Vercel 宣布用 "Agent 工厂"模式维护其 AI SDK 开源库——流程每一步(读 issue、改代码、跑测试、提 PR)都由 Agent 执行,人类只负责审和合并。运行约四周后,该工厂贡献了 35% 的已合并 PR、关闭了 70% 的七月遗留问题,未解决 bug 数同步下降。另有开发者透露,在 DeepSeek Harness 项目里约 20% 的提交与 PR 也由 OpenAI Codex 工作树生成——AI 已深度参与实际开源工程协作。

为什么值得关注:这接住昨天"放权后的安全反噬",但给了一个建设性样本——AI 不只是写业务代码,开始反向"维护开源基础设施"了。人类角色从"写代码的人"退到"reviewer/merger",而这恰恰是 Agent 最稳的落点:改动可评审、可回滚、有 CI 兜底。35%/70% 不是炫技数字,而是"开源维护这种枯燥高频的活,正被 Agent 系统性接管"的实证。对中小团队的含义:别只让 Agent 写功能,让它进日常——清 issue、补文档、修 floss,才是性价比最高的第一波。

3. Spotify 开源内部 vibe coded 工具 Xirp:99% 工程师在用,并行跑 50+ 编码 Agent

事件:8 月 11 日前后,Spotify 将内部 vibe coded 应用 Xirp 开源。据称其已被 99% 工程师使用,可并行运行 50+ 编码 Agent,并在 Claude、Gemini、Codex 之间无缝切换上下文,需企业邮箱登录。它本质是大厂把"自己造的 AI 编码工作台"对外放出,而非采购第三方。

为什么值得关注:这映射出 AI 编程工具的第三条路——从"买工具"到"自己造、再开源"。Xirp 的看点不在模型多强,而在工程实践:多 Agent 并行(50+)意味着任务被拆成很多独立子流同时跑;跨模型切上下文意味着不被单一厂商锁死,谁强用谁。对行业的提示:当头部公司都开始自研并开源内部编码平台,"通用编码 Agent"的护城河可能不在产品壳,而在多 Agent 编排与跨模型上下文管理这层软实力。

4. Dyna Robotics 用 100 万小时人类视频训出 DYNA-2:零样本合格率 87%、13 分钟微调开瓶盖

事件:硅谷初创 Dyna Robotics 发布旗舰世界动作模型 DYNA-2,彻底摆脱高成本机器人遥操作数据,直接用 超 100 万小时人类第一视角视频做深度预训练(相当于约 170 年连续清醒经验)。它采用"双重预测架构"——预训练阶段同时预测视频下一帧与下一动作,在未接触任何机器人硬件数据的背景下习得物体运动规律与接触物理,再把空间推理能力跨形态迁移到固定机械臂、人形、五指灵巧手等多种平台。实测:高精度制造任务成功率从约 20% 飙到 80%–90%;零样本客户现场部署合格率从 46% 升至 87%;仅用 13 分钟本土极少微调,就能控一对五指手拧开瓶盖;遇外力打断能自发恢复。

为什么值得关注:这是昨天"视频即学"路线(X Square HOST)的更激进一版——不再依赖遥操作数据,纯靠互联网人类视频跨形态通吃。它正面刚了具身智能最大的瓶颈"真实动作数据稀缺且昂贵":机械臂动作数据难求,人类视频却无处不在。DYNA-2 证明"数据规模的指数提升"本身就能换来跨硬件的物理直觉,13 分钟微调即见效,意味着小团队也能用便宜视频快速适配新机体。下一步看它在家庭/工业长尾任务上的持续泛化,以及"跨形态迁移"会不会牺牲精细操作的精度上限。

5. 深圳人形机器人"0755"进颐养院:在复杂照护场景里真干,不止 Demo

事件:在深圳,代号"0755"的人形机器人已进驻颐养院,承担日常巡查、物品递送、语音陪伴等基础照护。该院主要接收深圳户籍重度失能老人,照护场景复杂、服务标准严格——机器人"护理员"的落地,标志具身智能从 Demo 向真实服务场景跨越。同步地,浦东国地中心携手百联集团共建全国首个可持续迭代的商业零售人形机器人应用高地,把机器人放进真实商超动线。

为什么值得关注:这把昨天"全身协同/全模态"的技术进展,按到了最硬的验收场——真实照护与零售。实验室里打乒乓球再漂亮,落到颐养院要面对失能老人、不规则动线、突发状况,服务标准比炫技严苛得多;"0755"能上岗,说明机器人的可靠性已到"可被托付基础活"的门槛。商业零售高地则解决"可持续迭代"问题——场景常态化才能积累真实数据、反哺模型。具身智能的拐点从来不是某篇论文,而是机器人开始出现在我们日常不得不信任它的地方。

  • 资本侧:宇树科技 8/7 已完成 IPO 网上路演,自称人形出货量全球第一,标志国产人形从技术公司转向规模化交付上市公司。

小结

今天的主线是**"运行时开源、AI 反向养开源、内部工具开源化;视频跨形态预训练、机器人进真实照护"**。

AI 编程这条线,三件事层层递进:一是 Agent 运行时本体重开源(DeepSeek Harness v0.1, MIT + Cordis 可换模型工具),二是 AI 开始维护开源基础设施(Vercel Agent 工厂 4 周拿下 35% PR、70% 问题),三是 大厂把自研编码平台对外开源(Spotify Xirp,50+ Agent 并行、跨模型切上下文)。三者共同指向——编码智能体的护城河,正从模型沉到运行时与编排层,而这一层正被开源快速填平。

具身智能这条线,DYNA-2 用 100 万小时人类视频做到零样本 87%、13 分钟微调开瓶盖,把"视频即学"推到"完全无遥操作数据"的极端;深圳"0755"进颐养院、浦东商超高地,则把技术按进最硬的真实场景。这和昨天"全身协同 + 原生全模态"一脉相承——自主系统要先能协同、能被听懂,还要真能出现在我们不得不信任它的地方。

昨天关键词是"开源登顶、安全反噬、插件互通、全身协同、原生全模态",今天关键词是"运行时开源、AI 养开源、工具开源化、视频跨形态、场景落地"。明天继续。
