2026-08-26 AI新闻速递

Created2026-08-26|AI-MLAI-News
|Word Count:1.5k|Reading Time:5mins

今天 AI 圈的主线很清晰：coding agent 从「终端 / CLI」走向「协作空间与 IDE 原生」，具身智能在资本与「机器人大脑」叙事上加速，基础设施则进入「agentic 经济性」的硬碰硬竞争。以下筛选 5 条值得关注的动态，并附 3 条快讯与一段小结。

一、Slack Code 发布：把 coding agent 搬进项目频道

8 月 20 日，Slack 发布 Slack Code，把 AI 编程智能体直接放进项目频道（code channel），和人类队友同处一个对话空间。团队可以跟随 agent 的活动、审阅改动、查看实时 HTML 预览，也能随时让 agent 改方向、暂停或停止。

为什么值得关注：它把「写代码」这件事从终端里拽出来，塞回团队原本就在聊天的频道里——产品、设计、非工程同学不用开终端也能参与。高风险的「推到生产」动作仍需专家审批，agent 继承既有权限与安全策略。口号是 "No ticket, no meeting, no waiting – just a fix, shipped"。这代表 coding agent 的下一个形态：不是更强的 CLI，而是长在协作流里的「同事」。

二、Google Antigravity IDE 扩展正式发布，跨设备接管 Agent 会话

8 月 25 日，Google 的 Antigravity IDE 扩展正式发布，支持 VS Code、JetBrains、Zed 等主流编辑器，实现跨设备远程接管 AI Agent 会话——开发者可以在任意一台电脑调用云端的 agent 任务，本地 agent 协作能力升级。

为什么值得关注：过去 agent 会话被绑死在某一台机器、某一个 IDE 里；Antigravity 把「会话状态」变成了可迁移的资产。这对远程办公、多机协作和不中断任务流至关重要，也意味着 IDE 正在从「编辑器」演变为「agent 运行时的前端」。

三、OpenAI GPT-5.6 接入 AWS Kiro 并降价 20–33%

8 月 25 日，OpenAI 将 GPT-5.6（含 Sol 变体）接入 AWS 的 Kiro 开发平台，主打性价比：软件工程类任务调用成本显著下降，据称企业开发 agent 成本可降低约 82%。同时 GPT-5.6 系列在 OpenAI 侧再降价 20–33%。

为什么值得关注：coding 模型的价格战从「token 单价」打到了「端到端 agent 任务成本」。当顶级模型做日常编码的门槛被压下来，小团队和独立开发者第一次能在主力工作流里用上最强模型，而不是只在关键路径上精打细算。Kiro 把规划、构建、审查、测试串成一条线，降价直接放大了 agent 规模化落地的可行性。

四、小鹏机器人完成 9 亿美元首轮融资，IRON 年底量产

8 月 24 日，小鹏披露旗下机器人业务完成首轮超 9 亿美元融资，投后估值超 63 亿美元，创国内具身智能行业单轮私募纪录；腾讯、阿里战略投资，IDG 领投。资金用于物理 AI 模型研发与产线建设，IRON 人形机器人计划 2026 年底规模量产，2027 年面向零售、服务等行业客户销售。

为什么值得关注：资本正在提前为「物理 AI」独立定价——机器人从汽车业务之外的技术投入，变成了可以单独估值的资产。9 亿美元的量级说明具身智能已经从 demo 叙事进入「产线 + 交付」的硬指标阶段。结合世界机器人大会上「机器人大脑时代」的共识，2026 年底的量产节点会成为行业分水岭。

五、英伟达 Groq 3 LPX 投产 + Vera Rubin NVL72：智能体工作负载每兆瓦吞吐至上代 30 倍

8 月 24 日，英伟达宣布面向 AI 推理的 Groq 3 LPX 全面投产，并公布新一代 Vera Rubin 平台性能：在 SemiAnalysis AgentX 智能体工作负载、运行 DeepSeek V4 Pro 的测试中，Vera Rubin NVL72 每兆瓦吞吐量最高达上代 GB300 NVL72 的 30 倍，每 token 成本最高降 35 倍；Groq 3 LPX 主打低延迟 token 生成，在 Gemma 4 31B、10 万 token 上下文下达到每秒 3400 个输出 token。SpaceXAI 还计划把优化版 Vera Rubin 用于首代 Starmind AI 卫星，将算力延伸至轨道。

为什么值得关注：agentic 工作负载消耗的 token 数是普通聊天的 15 倍以上，基础设施的经济性正被重新定义。英伟达这次发布的不是单点算力刷新，而是「每兆瓦吞吐 / 每瓦 token / 每 token 成本」这套 agent 时代指标。当 agent 成为主流 workload，谁能把「智能工厂」的单位产出成本压下来，谁就握住了下一阶段的话语权。

快讯

  • OpenAI 升级前沿模型安全协议：宣布加强监控、对齐与安全保障，必要时可暂停训练运行，从「追求能力加速」转向更谨慎的迭代开发节奏。
  • 英特尔 Hot Chips 2026 发布三套智能体 AI 架构：Diamond Rapids 处理器（256 核、18A-P）、Crescent Island GPU（Xe3P）、Wildcat Lake SoC（17 TOPS NPU、首用 UCIe），覆盖数据中心到边缘的异构算力体系。
  • 匿名模型 Ox-Alpha 霸榜 OpenRouter：凭 104 万上下文窗口与多模态能力、领先的编程基准得分，预览期免费开放，厂商身份至今未公开，大量开源 agent 项目已大规模调用。

小结

今天的五条主线拼出一幅图：coding agent 正在「去终端化」——Slack Code 把它搬进协作频道，Antigravity 让它跨设备跟随，GPT-5.6+Kiro 把端到端成本打下来；具身智能在资本与大脑叙事上双加速——小鹏 9 亿美元融资把量产节点钉在 2026 年底；基础设施进入 agentic 经济性竞争——Vera Rubin 的 30 倍每兆瓦吞吐重新划定了智能工厂的成本曲线。agent 从「能写代码」走向「能进团队、能上产线、能算清账」，是这一周最清晰的信号。
