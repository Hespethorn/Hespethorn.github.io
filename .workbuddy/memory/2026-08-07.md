## 技术咨询：BM25 权重大但不相关（2026-08-07）

老周分享前司 OA 系统经验：BM25 分片 + 倒排索引按权重返回文档，出现"权重大但不相关"，迁移到 AI Agent 后依旧。已给出完整分析：
- 根因：BM25 三因子（IDF/TF/长度归一化）全是词法统计，无语义判断；词频堆砌、一词多义、同义异形、分片失真四类成因
- Agent 场景放大：检索器未换 + 分数被当可信度 + 混合检索融合策略粗糙
- 解法：两阶段检索（粗召回+rerank）、RRF 融合、查询改写、语义分片
- 配两张可视化图（成因示意 + 两阶段检索流程）
