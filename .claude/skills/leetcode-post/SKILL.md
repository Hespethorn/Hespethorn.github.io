# LeetCode 题解文章生成器

根据用户指定的 LeetCode 题目，生成符合博客规范的完整题解文章（Markdown 文件）。

## 文件输出位置

- Python 版：`source/_posts/Leecode/Python/leetcode NNNN - Problem Name.md`
  - 命名示例：`leetcode 0001 - two sum (python).md`
- C++ 版：`source/_posts/Leecode/C++/NNNN - YYMMDD - ProblemName.md`
  - 命名示例：`0001 - 240101 - two sum.md`

日期从 2024.01.02 开始，每篇新文章比上一篇晚 5 天。

## 6 条写作铁律（每条都不可违反）

1. **推荐必须明确** — 必须指名哪个最好+为什么。禁止"各有优劣"。
2. **表格优于纯文本** — 方法对比、复杂度、边界处理一律用表格呈现。
3. **具体高于抽象** — 每个结论必须有数值或例子支撑（如"n=10⁴ 时快 100 倍"）。
4. **手推演示例不可省略** — 用题目示例输入逐步追踪算法执行过程。
5. **全部解释用中文** — 除题目英文原文外，所有内容用中文。
6. **代码完整可运行** — import 齐全、类型标注到位、关键逻辑有中文注释。
