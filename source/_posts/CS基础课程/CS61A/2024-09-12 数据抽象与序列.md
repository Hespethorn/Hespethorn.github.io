## 一、数据抽象：用"接口"隔开"实现"

CS61A 强调一个思想：**数据 = 构造函数 + 选择器**。只要这两者行为一致，内部怎么存根本不重要——这叫**抽象壁垒（abstraction barrier）**。

以"有理数"为例，不关心它存成 tuple 还是两个独立变量，只约定接口：

```python
def make_rat(n, d):
    return (n, d)          # 构造函数：用元组存
def numer(r):
    return r[0]            # 选择器：取分子
def denom(r):
    return r[1]            # 选择器：取分母

def add_rat(a, b):
    return make_rat(numer(a) * denom(b) + numer(b) * denom(a),
                   denom(a) * denom(b))

r = make_rat(1, 2)
print(numer(r), denom(r))     # 1 2
```

输出：

```
1 2
```

上层 `add_rat` 只依赖选择器，从不直接碰 `r[0]`。哪天把底层换成字典，上层一行都不用改。

## 二、序列抽象（Sequence Abstraction）

Python 里 **序列（sequence）** 是一类"可按整数下标访问、有长度"的对象，共同接口是 `len()` 与 `seq[i]`。最常见的三种：

- **list**：可变，用 `[ ]`；
- **tuple**：不可变，用 `( )`；
- **str**：不可变字符序列；
- **range**：惰性整数序列（见篇七）。

```python
lst = [10, 20, 30]
t = (1, 2, 3)
s = "abc"
print(lst[0], t[1], s[2])    # 10 2 c
print(len(lst), len(t), len(s))  # 3 3 3
```

## 三、切片与列表推导

**切片** `seq[start:stop:step]` 取出子序列（左闭右开）：

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])      # [1, 2, 3]
print(nums[::2])      # [0, 2, 4]  每隔一个
print(nums[::-1])     # [5, 4, 3, 2, 1, 0]  反转
```

**列表推导**是"生成列表"的紧凑写法，等价于 `map` + `filter` 的组合：

```python
nums = [1, 2, 3, 4, 5]
squares = [x * x for x in nums if x % 2 == 1]
print(squares)        # [1, 9, 25]
```

输出：

```
[1, 9, 25]
```

## 四、为什么抽象重要

把"数据怎么存"和"数据怎么用"分开，是写大程序不崩的关键。篇五会看到：一旦引入**可变性**，抽象壁垒更容易被打破，所以理解"不可变序列（tuple/str）"和"可变序列（list）"的区别是必须的补丁。

## 五、小结

- **数据抽象** = 构造函数 + 选择器，用接口隔离实现。
- **序列**统一接口：`len()` 与下标访问；list 可变、tuple/str 不可变。
- **切片** `[start:stop:step]`、**列表推导** `[... for ... if ...]` 是日常主力。
