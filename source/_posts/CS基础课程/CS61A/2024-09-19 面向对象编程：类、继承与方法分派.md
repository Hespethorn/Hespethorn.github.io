## 一、类与实例

**类（class）** 是对象的蓝图，**实例（instance）** 是按蓝图造出的具体对象。属性与方法都挂在实例上，`self` 指"当前实例"。

```python
class Dog:
    def __init__(self, name):
        self.name = name          # 实例属性
    def bark(self):
        return f"{self.name}: 汪!"

d = Dog("阿黄")
print(d.bark())                   # 阿黄: 汪!
```

输出：

```
阿黄: 汪!
```

`__init__` 是构造器，创建实例时自动调用；`self` 是约定俗成的第一个参数，代表"这个实例自己"。

## 二、方法就是带 self 的函数

类里的函数叫**方法**。调用 `d.bark()` 时，Python 自动把 `d` 作为 `self` 传进去。这与篇二"函数是对象"一脉相承——方法本质是绑在类上的函数。

## 三、继承：复用与特化

**继承**让子类获得父类的属性和方法，并可覆盖（override）：

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return "..."

class Cat(Animal):                # Cat 继承 Animal
    def speak(self):
        return f"{self.name}: 喵~"

class Dog(Animal):
    def speak(self):
        return f"{self.name}: 汪!"

print(Cat("咪咪").speak())        # 咪咪: 喵~
print(Dog("阿黄").speak())        # 阿黄: 汪!
```

输出：

```
咪咪: 喵~
阿黄: 汪!
```

子类没写 `__init__` 就用父类的；写了 `speak` 就**覆盖**父类版本。

## 四、方法分派与 MRO

当调用 `obj.method()`，Python 沿 **MRO（方法解析顺序）** 查找方法：先实例自己、再当前类、再按继承顺序往上，找到第一个就停。

```python
class A:
    def hi(self): return "A"
class B(A):
    def hi(self): return "B"
class C(A): pass                  # C 没写 hi，继承 A 的

print(B().hi())                   # B（自己的）
print(C().hi())                   # A（沿 MRO 找到父类）
```

输出：

```
B
A
```

多继承时 MRO 遵循 **C3 线性化**（简单记：按 `__bases__` 顺序深度优先、去重保序）。复杂继承树下，理解 MRO 才能预测"调的是哪个方法"。

## 五、面向对象设计要点

- **把数据和行为绑在一起**，比满地散函数更好维护；
- **优先组合（has-a）而非继承（is-a）**，继承链过深易脆；
- **覆盖方法时常用 `super()`** 调用父类版本，避免重复代码。

## 六、小结

- **类**是蓝图，**实例**是对象，`self` 指自己。
- **继承**复用代码，子类可覆盖父类方法。
- 方法查找走 **MRO**：实例 → 类 → 父类（第一个命中即停）。
