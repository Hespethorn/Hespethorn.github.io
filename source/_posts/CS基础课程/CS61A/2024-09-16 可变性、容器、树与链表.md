## 一、可变 vs 不可变

**不可变（immutable）**：创建后内容不能改——`int`、`float`、`str`、`tuple`、`frozenset`。
**可变（mutable）**：创建后能改内部——`list`、`dict`、`set`、自定义类实例。

```python
s = "abc"
# s[0] = "x"     # 报错：str 不可变
lst = [1, 2, 3]
lst[0] = 99      # list 可变，OK
print(lst)       # [99, 2, 3]
```

输出：

```
[99, 2, 3]
```

## 二、别名与共享引用（"盒子与指针"模型）

可变对象最坑的一点是**别名**：两个名字指向同一个对象，改一个另一个也变。

```python
a = [1, 2, 3]
b = a           # b 和 a 是同一个列表的别名
b.append(4)
print(a)        # [1, 2, 3, 4]

c = a[:]        # 切片做出副本，不再是别名
c.append(5)
print(a, c)     # [1, 2, 3, 4] [1, 2, 3, 4, 5]
```

```
a ──┐
    ▼
  [1,2,3,4]  ←── b        （a、b 共享）
c ──▶ [1,2,3,4,5]          （独立副本）
```

**判定是否共享**：用 `a is b`（身份比较），而 `==` 只比值。

## 三、容器：dict 与 set

```python
d = {"name": "Ada", "age": 36}
print(d["name"])             # Ada
d["age"] = 37                # 改值
s = {1, 2, 2, 3}            # set 自动去重
print(s)                     # {1, 2, 3}
```

输出：

```
Ada
{1, 2, 3}
```

## 四、链表 Link（CS61A 经典可变结构）

链表由一个 `first`（首元素）和一个 `rest`（指向下一个 Link，或 `Link.empty`）组成：

```python
class Link:
    empty = ()
    def __init__(self, first, rest=empty):
        self.first = first
        self.rest = rest
    def __repr__(self):
        if self.rest is Link.empty:
            return f'Link({self.first})'
        return f'Link({self.first}, {self.rest})'

ll = Link(1, Link(2, Link(3)))
print(ll)                 # Link(1, Link(2, Link(3)))
print(ll.rest.first)      # 2
```

输出：

```
Link(1, Link(2, Link(3)))
2
```

这是**递归数据结构**：每个 `rest` 又是一个 Link，天然和递归遍历配对。

## 五、树 Tree

树有一个 `label` 和若干 `branches`（子树的列表）：

```python
class Tree:
    def __init__(self, label, branches=()):
        self.label = label
        for b in branches:
            assert isinstance(b, Tree)
        self.branches = list(branches)
    def __repr__(self):
        if not self.branches:
            return f'Tree({self.label})'
        return f'Tree({self.label}, {self.branches})'

t = Tree(3, [Tree(1), Tree(2, [Tree(4)])])
print(t.label, [b.label for b in t.branches])   # 3 [1, 2]
```

## 六、小结

- **不可变**：int/str/tuple；**可变**：list/dict/set/实例。
- 可变对象警惕**别名共享**——改一处影响多处，用切片/`copy` 做副本。
- **Link / Tree** 是递归结构，遍历用递归最自然。
