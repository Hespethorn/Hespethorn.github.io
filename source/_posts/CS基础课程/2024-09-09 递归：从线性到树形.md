## 一、递归三定律

递归 = 函数**自己调用自己**。一个正确的递归必须满足三条：

1. **有一个或多个基例（base case）**：不再自我调用，直接返回；
2. **每次递归都在向基例化简**：问题规模变小；
3. **递归调用解决子问题**，再组合结果。

## 二、线性递归：一条直链

阶乘是最干净的线性递归——每次调用把问题缩小 1：

```python
def factorial(n):
    if n == 0:            # 基例
        return 1
    return n * factorial(n - 1)   # 向基例化简
```

调用 `factorial(3)` 的展开（结合篇一的环境模型理解）：

```
factorial(3)
= 3 * factorial(2)
= 3 * (2 * factorial(1))
= 3 * (2 * (1 * factorial(0)))
= 3 * (2 * (1 * 1)) = 6
```

## 三、斐波那契：重复计算的代价

```python
def fib(n):
    if n == 0 or n == 1:      # 两个基例
        return n
    return fib(n - 1) + fib(n - 2)
```

`fib(5)` 会重复算 `fib(3)`、`fib(2)` 多次——这是**树形递归**的经典缺陷：子问题大量重叠，时间复杂度指数级。后面篇七讲效率时会用"记忆化"修它。

## 四、树形递归：分支求解

树形递归一次产生多个递归调用，天然适合"组合/枚举"类问题。例：用硬币凑出金额 `n` 有多少种方式（硬币 1/5/10/25）：

```python
def count_change(n, coins=(1, 5, 10, 25)):
    if n == 0:
        return 1            # 刚好凑完，算一种
    if n < 0 or not coins:
        return 0            # 凑不出
    use = count_change(n - coins[0], coins)        # 用一枚当前硬币
    skip = count_change(n, coins[1:])              # 换下一种硬币
    return use + skip

print(count_change(10))     # 4 种：10 / 5+5 / 5+1*5 / 1*10
```

输出：

```
4
```

它画出的是一棵**调用树**：每个节点分出"用/不用"两条枝，叶节点是基例。

## 五、递归 vs 迭代

同一问题常有两种写法。阶乘的迭代版：

```python
def factorial_iter(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result
```

- **递归**：贴合问题结构（尤其树形），代码短、易读，但调用有栈开销；
- **迭代**：用循环+累加变量，通常更省内存，但复杂结构写起来绕。

选型原则：问题本身有"自相似"结构（树、分治、回溯）时优先递归；纯线性累加用迭代更直白。

## 六、小结

- 递归三定律：**基例 + 化简 + 组合子问题**。
- **线性递归**一条链，**树形递归**多分支（小心重复计算）。
- 递归贴结构、迭代省内存，按问题形状选。
