## 一、函数是"一等公民"

在 Python 里，函数和数字、字符串一样，是**对象**。这意味着函数可以：当作参数传给别的函、作为返回值、存进变量。能这么做的函数，叫**高阶函数（higher-order function）**。

```python
def square(x):
    return x * x

f = square        # 函数赋值给变量
print(f(4))       # 16
print(type(f))    # <class 'function'>
```

输出：

```
16
<class 'function'>
```

**C++ 对照**：C++ 里函数不是一等公民，要"把函数当值传"得用**函数指针**或 `std::function`（C++11 起），且语法繁琐；Python 原生把函数当值，是动态语言的核心便利。

## 二、把函数当参数：自己实现 map / filter / reduce

高阶函数最经典的三种用法，Python 内置了 `map`/`filter`，但理解它们最好自己写一遍：

```python
def my_map(fn, seq):
    result = []
    for item in seq:
        result.append(fn(item))
    return result

def my_filter(pred, seq):
    result = []
    for item in seq:
        if pred(item):
            result.append(item)
    return result

nums = [1, 2, 3, 4, 5]
print(my_map(lambda x: x * x, nums))        # [1, 4, 9, 16, 25]
print(my_filter(lambda x: x % 2 == 0, nums)) # [2, 4]
```

输出：

```
[1, 4, 9, 16, 25]
[2, 4]
```

## 三、lambda：一次性匿名函数

`lambda` 用来写没有名字的小函数，适合只在一处使用的场景：

```python
add = lambda a, b: a + b
print(add(3, 4))                 # 7
# 等价于：
def add2(a, b):
    return a + b
```

注意：`lambda` 只能写一个表达式（不能写多行语句），复杂逻辑还是用 `def`。

## 四、函数返回函数：把"行为"封进闭包

高阶函数不仅能收函数，还能**返回函数**——这引出了 CS61A 最重要的概念之一：**闭包（closure）**。返回的函数"记住"了定义时所在环境的变量。

```python
def make_adder(n):      # 返回一个"加 n"的函数
    def adder(x):
        return x + n    # n 被封闭在 adder 里
    return adder

add5 = make_adder(5)
add10 = make_adder(10)
print(add5(3))         # 8
print(add10(3))        # 13
```

输出：

```
8
13
```

`make_adder(5)` 返回的 `adder` 记住了 `n=5`；`make_adder(10)` 记住了 `n=10`。这就是**函数工厂**——用一份模板批量造出行为各异的函数。

## 五、小结

- **高阶函数** = 收函数做参数、或返回函数的函数。
- **lambda** = 一次性匿名函数，适合简单表达式。
- **闭包** = 返回的函数带着定义时的环境，能"记住"外部变量。
