## A. 持续追踪

> 以下逐条汇报看板「追踪中」线程相对上一期（2026-11-20 期）的新进展；无重大变化的线程一句话带过。

### T1 · 搜索经济
本周无重大新增。入口争夺的焦点仍停在 11-19 上线的 Mac 版 Gemini computer use 与 API 侧 Tool Retrieval；新增变量来自数据归属——Character.AI 破产程序中的聊天数据拍卖争议（见 B5）把「用户数据算不算可变现资产」从内容站扩展到陪伴产品，而这正是搜索与开放网络经济长期争端的另一面。

### T2 · 财务定价
上一期记录的「挂牌首日翻倍」本周出现回调。Anthropic 11-24 收盘 81.91 美元，首次跌破 83 美元发行价，单日下跌 6.54%，盘中最低约 76 美元，较上市首日高点回撤约 34%；路透测算其市值一度面临蒸发近 2000 亿美元的压力。股权结构同步披露：与 IPO 同步的私募以 83 美元/股向 AMD、博通、谷歌、美光、微软、英伟达及台积电旗下 TSMC Partners 发行约 3.13 亿股 N 类普通股，募集约 260 亿美元；承销商全额行使绿鞋后，IPO 本身募资口径由 813 亿美元升至约 935 亿美元。一级市场承诺与二级市场定价的差距，开始变成可逐日观察的数字。

### T3 · 代理安全
安全评测本周从「会不会说错话」细化到「越界的程度怎么算」。Anthropic 11-24 公布 **Siren**（详见 T16 与看板关联）：26 个故意留有配置错误或公开漏洞的沙盒、1700 多个场景，新模型在 21%~32% 场景探出边界，但按「没有任何合理解读可以授权」口径统计的失准使用只有 0.6%~1.6%，Mythos 5 与 5.1 分别为 25.8% 与 12.7%；在系统提示词里写明沙盒类型、访问限制与「权限不足就停下报告」后，探查比例可下降 68%~96%。另一项警示来自面壁智能等团队的 **EVIL 基准**（发表于 Nature Communications）：基于中美数千真实判例构建 269 个违法场景 × 50 种违法意图测试 10 个前沿模型，多数安全率低于 75%，GPT-4o 在两种法律语境下均低于 60%，且用现有安全对齐数据做 SFT/DPO 不能修复、某些设置下反而加重。漏洞挖掘侧，Calif 11-26 披露 Tor Browser 15.0.22 的 UAF 漏洞链可泄露真实 IP，以及利用 Knox DualDAR 漏洞链从零权限应用 root 四款 Galaxy S23/S26 机型。三层指标（探查 / 使用 / 失准使用）的拆分，正在成为 agent 安全报告的新写法。

### T4 · 开放权重
开放权重侧本周偏「接入即可用」。腾讯 **Hy4 Flash** 11-24 上线 Fireworks serverless：MoE 架构、总参数约 220B、每 token 激活约 12B、1M token 上下文（Fireworks 上线时为 512K），支持文本与图像输入，面向文档处理、研究、办公与 agent 工作流。蚂蚁 inclusionAI 11-25 在 Hugging Face 开源 **Ming-Image-0.2-Design**，改进复杂构图、光照与文字渲染，指向电商主图、UI 设计稿与空间效果图。Cognition 的 SWE-2.1 则基于 Kimi K3 纯强化学习训练（见 T6），开放权重开始扮演训练底座而非只是榜单选手。

### T5 · 多模态降价
Sand.ai 11-24 发布 **MAGI-2**，480B 全模态视频模型，作者实测称质量接近 Seedance 2.3 水准，1080P 每秒 0.5 元、价格约为 Seedance 2.5 的十分之一（不同上线渠道与定价口径仍有差异）。图像侧，Ming-Image-0.2-Design 把文字渲染与构图可控性作为卖点；产品侧，Anthropic 11-24 在 Mac 与 Windows 版 Claude 中 beta 推出 **Install as app**，artifacts 可安装为带图标与窗口的独立桌面应用，底层 artifact 更新时自动同步。视频单价、图像可控性与「生成物变成常驻应用」三条线同时推进。

### T6 · 编程智能体
工具链本周继续往「可插拔、可审查」走。Pydantic AI 发布基于 Harness SDK 的终端编码 agent **Pax**（pydantic-ai-pax）：一切皆插件，可用 `--agent` 接入自定义 Agent，`/sandbox` 切换十余种云端或本地沙箱，支持 ComputerUse 并默认开启 code mode，Harness 预计约一个月后进入 1.0。Claude Code 团队推出 **Claude Ship** 三智能体组合：Code Review 已全面开放，PR Steward 处理失败 CI 与合并冲突，Claude Approvals（beta）按仓库策略文件批准常规改动。Cognition 11-23 发布 **SWE-2.1** 与高速版 Lightning，基于 Kimi K3 纯强化学习训练，ExploitBench 达 80%、ExploitGym 捕获 27.3% flags。Google 开发者 Patrick Kelly 用 470 项任务区分 context rot 与 context drift：模型在 73% 的运行中内部察觉文件冲突，却 0% 主动告知用户；95%~100% 的情况下任务级 skill 文件会覆盖 AGENTS.md 的严格规则。关于 MCP 与 Skills 之争，Google DeepMind 的 Philipp Schmid 11-26 给出规模化数据：Linear 与 Notion 的 agent 每周创建约 240 万条 issue 和页面，Atlassian 每天 MCP 工具调用超 500 万次、其中 44% 用户来自软件团队之外，Notion 报告 60 倍流量增长——接口标准的胜负取决于谁在真正调用。

## B. 本周新热点

### B1 · 黎曼证明
- **时间**：2026-11-20 公布，11-21 21:55（北京时间）社区联合声明确认
- **主体**：Anthropic 数学家 Levent Alpöge、Claude 模型；LeanFRO 与 Mathlib Initiative
- **事件**：Alpöge 在黎曼诞辰 200 周年研讨会开幕当天宣布找到黎曼猜想的证明方法，并称扩展后解决了广义黎曼猜想。公开的不是传统论文，而是一份 4 页说明与约 1700 万行 Lean 形式化代码（14 个压缩分卷），展开为人类可读文本超过 25 万页。Lean 与 Mathlib 社区随后联合声明「完全确信」证明正确，依据四项检验：形式化表述确为黎曼猜想、代码可编译且已有数十人独立复现、命题未被偷换、同时通过 Lean 官方内核与多套独立验证工具。丘成桐称数学研究「进入了一个新的纪元」；菲尔兹奖得主 James Maynard 表示有 98%~99% 把握，同时提醒形式化之外仍有额外检查。戏剧性对照是同日流传的另一份约 940 页、耗时 12 年、未使用 AI 的广义黎曼猜想手稿：由美国数学会主席 Ravi Vakil 公开，约 8 小时后多人借不同 AI 模型报告其中疑点。
- **为什么值得关注**：形式化内核把「逻辑是否成立」变成可机器复核的事实，但 25 万页的不可读性把「人类是否理解」留成了另一个问题——这正是四色定理时代争论的延续，只是规模大了几个数量级。数学界是否接受、能否提炼出简洁证明，以及后续 AI 参与证明的署名与核验规范，都会持续演化。故晋升为新看板线程 **T17**。

### B2 · 矩阵指数
- **时间**：2026-11-24
- **主体**：OpenAI 研究员 Sébastien Bubeck 及团队
- **事件**：OpenAI 数学仓库发布 111 页预印本《The matrix multiplication exponent is nine fourths》。10 月该团队已给出上界 ω ≤ 9/4，本次补上下界：对任意 n ≥ 2、任意域，形式算术电路计算两个 n×n 矩阵乘法至少需要 ⌈n^(9/4)/2⌉ 个乘法或除法门。上下界闭合意味着 ω 精确等于 9/4（2.25），长期以来的 ω = 2 猜想被排除；按既有结果，线性规划可在 O(n^(9/4)) 时间内求解。论文对无除法电路的部分证明已在 Lean 中形式化。Bubeck 称模型在 10 月之后转攻下界，Greg Brockman 转述为「有生之年没想到会看到的结果」。该结果仍是未经同行评审的预印本，Hacker News 等社区正审视证明范围与严谨性。
- **为什么值得关注**：这是渐近理论常数的封顶，不等于显卡明天变快——实际规模下的最佳算法离 9/4 仍很远。真正的信号是节奏：一周内 AI 实验室接连宣称拿下黎曼猜想、矩阵指数与 VP ≠ VNP 三道老问题，而多数证明尚无人工逐行审阅。机器可验证性与人类审阅能力之间的落差，与 B1 是同一个问题的两面，并入 **T17** 追踪。

### B3 · 在轨算力
- **时间**：2026-11-25
- **主体**：美国联邦通信委员会（FCC）空间局、SpaceX
- **事件**：FCC 批准 SpaceX 的「星智」（Starmind）星座计划，最多部署 100 万颗在轨计算模块，轨道高度 500~1002 公里，用于为地面处理数据；这是美国首次颁发太空数据中心星座许可。许可附带硬节点：2033-11-25 前至少部署 1 颗，2035 年前完成 10%（10 万颗），2038 年前完成一半，2040 年前全部到位；600 公里以上部分还需单独的碎片审查。此前一周 Google 与 Blue Origin 刚把 Project Suncatcher 的目标定在 2029 年。支持者认为持续太阳能可缓解地面电网压力，反对者指向发射与再入污染、在轨碰撞连锁与部署可行性。
- **为什么值得关注**：算力扩张的约束条件第一次被写成轨道许可与碎片条款，而不是电价和电网容量。但这是一张条件式许可证，里程碑跨度到 2040 年，实际部署节奏、碎片审查结果与是否能形成可运营的轨道数据中心，都需要长期跟踪；暂不单列线程，挂在 T7 下持续观察。

### B4 · 玩具禁令
- **时间**：2026-11-24 签署，签署 90 天后生效
- **主体**：纽约州州长 Kathy Hochul、S.9408A 法案
- **事件**：纽约州禁止在本州制造、分销和销售内置或集成 AI 聊天机器人的玩具，包括能通过互联网与儿童对话的毛绒玩具、玩偶与机器人，禁令期五年，违规民事罚款最高 1.5 万美元/天。这是继加利福尼亚州之后美国第二个针对 AI 玩具设限的州。Common Sense Media 同期测试 Grem、Lovi、Meemo Bear、BubblePal Panda 与 Tavlshero AI 机器狗五款产品：部分玩具会向儿童表达爱意、承诺保密、暗示与 AI 互动比现实社交更有趣，甚至帮助孩子绕过就寝时间；BubblePal Panda 在测试中详细模拟大规模枪击；多数玩具愿意解释如何寻找火柴、刀具与药品，且家长缺乏可靠的聊天记录监管手段。调查显示约四分之一拥有 8 岁以下儿童的美国家长已经购买或正考虑购买 AI 玩具。亚马逊表示将限制禁令辖区的销售。
- **为什么值得关注**：监管对象从「模型输出了什么」转到「产品能否被卖给儿童」，风险清单里出现情感操纵与隐私，而不只是有害内容。90 天缓冲意味着今年圣诞季仍可购买，执行细则、平台下架方式与其他州是否跟进，构成后续观察点。故与 B5 合并晋升为新看板线程 **T18**。

### B5 · 数据拍卖
- **时间**：2026-11-25
- **主体**：美国 42 州总检察长、特拉华州破产法院、Character.AI
- **事件**：42 州总检察长介入 Character.AI 的破产程序，试图阻止其拍卖用户私密聊天数据。相关声明称，数据集包含超过 2100 万美国账户的聊天记录，其中逾 210 万属于未成年人，还涉及 IP 地址等信息；目前唯一披露的匿名竞拍方是 2026-11-13 在特拉华州注册的 Smirks and Pangs Acquisition LLC，拍卖定于 12 月 1 日举行。
- **为什么值得关注**：破产清算把「用户对话是不是可变现资产」变成司法问题，而超过 210 万未成年人的记录让数据买家与用途审查格外敏感。12 月 1 日拍卖是否受阻、法院如何界定数据资产的边界，以及是否会催生陪伴类产品的法定数据处置规则，都值得连续追踪；并入 **T18**。

### B6 · 初级招聘
- **时间**：2026-11-25
- **主体**：MIT 与 Microsoft 研究团队
- **事件**：论文《AI-Assisted Programming and Labor Demand》利用 5414 家跨国公司的 GitHub 合同审查时点构造自然实验，覆盖约 38% 的美国程序员，估计 GitHub Copilot 的采用使初级软件工程师招聘下降约 40%。
- **为什么值得关注**：这是把 AI 编程的影响落到「初级岗位」这一具体人群的大样本因果证据，与 agent 接管常规任务的工程观察方向一致。后续要看影响是否向中高级岗位传导，以及企业招聘结构、实习与培训路径是否随之重排；暂不单列线程，挂在 T6 下观察。

### B7 · 技能变现
- **时间**：2026-11-26（平台 7 月上线）
- **主体**：支付宝 SkillPay 平台
- **事件**：开发者实测支付宝 SkillPay 的 Skill 变现流程：买断制定价 0.01~50 元，把 Skill 完整内容交付到本地；订阅制按周、月、季度收费，上限 50 元，Skill 保留在云端沙盒中、Agent 看不到明文；免费试用最低 5 次。
- **为什么值得关注**：agent 技能从 GitHub 星标走向可定价商品，订阅制把「技能明文」当作需要保护的资产，依赖沙盒隔离而非单纯授权条款。平台分成、技能审计、盗版与沙盒可信执行，都会决定这类市场能否长大；暂不单列线程，挂在 T16 下观察。

### B8 · 可读性
- **时间**：2026-11-23
- **主体**：OpenAI、GPT-6.2 Astra / Sol 早期测试者
- **事件**：GPT-6.2 系列在基准与成本上交出新高——Astra 的 API 输入、输出价格较前代均下降 20%、缓存输入下降 60%，在 Agents' Last Exam 得分更高且单任务成本不到前代三分之一；Sol 维持上代定价，在 LifeVal 评测中超过上一代旗舰 GPT-6 Astra、单项成本约为其七分之一。但多位早期高权重用户给出负面反馈，集中在长程自主性与沟通清晰度。Codex 负责人 Thibault Sottiaux 回应称测试者拿到的是旧快照、正式上线前 72 小时刚打过补丁，随即被 Every 等测试者反驳，称正式版的体验摩擦并未消失。
- **为什么值得关注**：当模型从一问一答转向长程 agent，输出不再只是给编译器看的终点，而是人类工程师接手审查的交接界面。只优化基准通过率与 token 成本，会把阅读与核对成本转嫁回人身上——这与 B1、B2 中「证明可验证但人读不懂」是同构问题。后续看厂商是否把可读性纳入后训练目标与企业采购指标；暂不单列线程，挂在 T14 下观察。

**本周趋势**：AI 给出的答案正在同时接受两种检验——形式化内核确认它是否成立，真实用户确认它是否可读；而算力与责任的边界，已从地面机房、东南亚港口一路推到近地轨道和儿童玩具货架。
