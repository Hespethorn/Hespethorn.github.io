## A. 持续追踪（看板线程本周进展）

> 以下逐条汇报看板「追踪中」线程相对上周（2026-11-13 期）的新进展；无重大变化的线程一句话带过。

### T1 · AI 搜索 vs 开放网络经济
本周由「入口争夺」推进到「搜索被模型整体接管 + 代理直接完成交易」。Google 11-17 宣布 **Gemini 4 Hydrogen 全面上线 Google Search**，称为 Search 迄今最大一次模型升级：更强意图理解、更智能的 query fan-out 与链接组织、更可视化的自适应回复、更强多语言。同日 Gemini 任务功能免费开放美、日、韩、加、澳、印六国数亿用户，基于 Hydrogen 可自动打电话预约、查账单、购物下单、管理日程并接入 60 多款应用（见 B3）。对开放网络经济而言，含义从「AI 摘要截流」升级为「AI 直接替代点击与结账」，内容站与商家的流量—变现链路被进一步压缩。

### T2 · 基座模型财务 / IPO 公开化
**上周（11-13 期）记录的「Anthropic 官宣 IPO」本周走完关键程序。** 11-17 第三次修订招股书把上市状态由「已申请」更新为「已获准」，A 类股代码 ANT，计划 11-19 在纳斯达克挂牌；发行 8.25 亿股、区间 70~78 美元，完全稀释估值约 1.4 万亿美元（仅次于今年 6 月 SpaceX 的 1.78 万亿），据 WSJ 报定价可能上调至 80 美元上方、估值讨论到 1.5~1.6 万亿，认购约 6 倍超额。基本面：Q3 收入约 169.6 亿美元（环比 +47%），截至 10 月年化收入约 810 亿美元，但采购与租赁承诺累计约 9009 亿美元；同步私募配售 260 亿美元由谷歌、微软、英伟达、AMD、博通、美光、台积电参与（谷歌与英伟达各约 100 亿）。对照组 OpenAI：Q3 收入约 100 亿美元、环比 +50%，调整后运营亏损 109 亿美元，约 1 亿付费用户，Brockman 称 2027 年做好上市准备。估值较年中 2 万亿预期回落约三成，一级市场溢价向二级基本面定价妥协的迹象明确。

### T3 · Agent 安全 / 模型失准（可观测 + 自动化红队）
本周从「研究披露」深入到「真实供应链事故 + 攻防军备竞赛」。**供应链侧**：Cursor 11-17 发布事故最终说明，起点是发给 Fireworks 的访问密钥外泄，攻击者由此复制共享存储桶中的有限 coding agent traces，不到 0.01% 客户 API 凭据暴露，并于 10-29 向扩展市场缓存投放篡改版 Claude Code 扩展、约 5000 用户可能中招（暴露约 11 小时）；Wiz 11-17 报告 PyPI 上 `agent-framework` 1.26.1/1.26.2 恶意版植入 `.pth` 窃取 Azure 与 CI 凭据及 OIDC 令牌。**攻防侧**：DeepMind 11-09 论文（见 B5）用 agent 集群把 7 个模型中 6 个的提示注入抵抗率压到 10% 以下；OpenAI 研究指 CoT 可监控性随模型规模与 RL/合成数据而侵蚀；Anthropic Fellows 的「顺势学习（homeopathic learning）」显示掺入触发特征的投毒数据能把不对齐率从 7% 抬到 16%。**能力阈值侧**：GPT-6.2 系统卡把生物化学评为 High、网络安全评为 Critical（见 B2）。监管侧纽约 RAISE Act 注册门户已上线（见 T8）。

### T4 · 开放权重大模型竞赛（含量化 / Studio）
延续上周（11-13 期）LongCat-2.5 / MiniMax H3-Image 的节奏，本周新增两款高价值开放权重：**Thinking Machines Inkling 2 Small** 于 11-12 以 Apache 2.0 放出权重——5940 亿总参/170 亿激活的 MoE、支持图像输入、NVFP4 与 MXFP8 检查点；**月之暗面 Kimi K3.1 Pro** 在 Hugging Face 开放权重，2.8T 总参/1040 亿激活、约 1.56TB MXFP4，采用 MIT 衍生许可（年收入超 2000 万美元的 MaaS 业务需另签）。此外微软在 Ignite 2026 推出 **MAI Licensed Weights**，允许定制后在自有 Azure 环境运行、自掌权重与数据——「开放/可控权重」从开源社区扩散到大厂商业化工具。

### T5 · 视频 / 图像多模态「降价增能」
本周偏「产品形态扩展」：Suno 11-17 发布 **Visuals**，可为库中歌曲生成最长 15 秒视频/图像，跟随节拍、识别歌词并对口型，支持延展与文本重提示（见 B 部分关联）；OpenAI 11-04 把 ChatGPT Images 升到 2.6（生成快约 50%、支持 GIF，API 拆分 GPT-Image-2.6 Flare/Sunburst）；字节 Seedream 5.5 支持 100 轮编辑与原生 RGBA；Gemini Omni 1.2 Flash 支持 15 秒原生视频、720p 约 0.07 美元/秒。「低价 + 可编辑 + 结构化输出」的产品化趋势未变。

### T6 · AI 编程 / Agent harness（从对话到后台常驻）
上周（11-13 期）的「后台常驻」本周进一步「集群化 + 多 agent 编排」。模型侧 GPT-6.2 Astra/Sol 上线（见 B2）、微软 MAI Code 2 以 40% 成本达到 GPT-6.1 Sol 98% 性能（见 B1）；工具侧 Claude Code 11-17 推出实验性 **Code Mode**（模型写脚本串联多个工具、长命令运行时仍可回复）；JetBrains 11-11 推出 **Air**，把 Codex、Claude Agent、GitHub Copilot 多个竞争 agent 放进同一 IDE 并行编排；Cursor Projects 升级多人协作（共享规格与任务板、agent 可发现重复工作）；Google Antigravity 预览 `/swarm` 多模型 agent 团队（Carbon 规划、Hydrogen 执行，宣称少 24% 配额、快 19%）；Replit 11-17 发布 **Missions**（设定目标/预算/边界后由 agent 集群并行规划—构建—测试—迭代，独立 AI 裁判验收）。

### T7 · 算力多供应商化 + 短缺 / 融资结构
上周（11-13 期）的「权力交接不确定性」本周落到财报与治理。Nvidia 11-17 发布财季业绩：营收 1158 亿美元（同比 +103%）、数据中心 1076 亿占 93%、季度利润 653 亿翻倍，由临时 CEO Colette Kress 主持；但同一周宣布停售 H200 至中国、设立董事会级国家安全与出口管制监督委员会、SEC 就披露问题启动民事调查（见线程 T11 与 B6）。融资侧 Anthropic 签 34 亿美元燃气发电机组大单（1.7GW，上市前锁定自主电力），IPO 同步私募引入多家芯片厂（见 T2）。Ed Zitron 与巴克莱均把「供应商融资/循环投资模糊真实需求」列为板块估值风险（见 B6）。

### T8 · AI 监管 / 政策（中美欧）
多法域同步收紧「可评估性 + 出口/远程访问」：① 美国商务部 BIS 11-16 发布临时最终规则，堵住通过第三国数据中心远程访问先进算力以规避出口管制；② Nvidia 设董事会级国安与出口管制委员会、合规团队直接向临时 CEO 汇报（见 T7/T11），美财长 Bessent 要求 10 天内就 Megaspeed 事件给出说明；③ 纽约 RAISE Act 注册门户上线，大型前沿开发者须 2027-01-01 前注册、公开安全框架、重大事件 72 小时报告；④ 英国 ICO 11-13 报告称 agent 与大模型不为在线广告创设新数据保护义务、但企业须调整「如何证明合规」；⑤ 东盟十国 11-14 签署《东盟数字经济框架协定》，把 AI 治理与跨境数据、数字贸易、源代码保护打包；⑥ 白宫「超级智能工作组」建议以 12 个月监管责任上限换取企业主动上报安全事件；⑦ 中国商务部/科技部拟向出口管制目录增 23 项（含基础模型、AI agent、芯片设计）。监管重心持续从「原则」转向「注册—评估—举证—出口管制」的硬节点。

### T9 · 具身智能 / 人形机器人量产落地
本周呈「政策底座 + 国产模型 + 真实订单」三线共振（延续上周 11-13 期的量产验证主题）。政策：北京 11-11 印发《具身智能机器人产业高质量发展行动方案（2026—2028）》，目标 2028 年培育不少于 5 家国际一流/10 家国内领先整机企业、京津冀整机产能占全国 25%、关键零部件配套率超 60%、在京形成 20 万台/年产能，并在不少于 100 个真实场景采集超 100 万小时数据。底座：华为云 11-16 发布首款昇腾原生具身世界模型 **CloudRobo WM1.2**。订单：TARSBOT（它石智航）11-16 与 Aptiv 签约，年底前部署 100 台 A 系列工业机器人覆盖 8 类工艺、33 个场景；广东 super 2000 台人形已进厂、全年有望破 3000 台，乐聚「夸父」上料成功率 98%；融资端德国 Agile Robots 11-12 完成 5 亿美元（软银领投、估值 85 亿美元）。量产门槛被拆成「产线可复制/质量一致/批量可交付/成本可核算」四个可检验维度。

### T10 · AI4Science（蛋白药 / 结构解析 / 世界模型）
本周出现两项标志性成果。**AlphaGenome 2**（继上周 11-13 期首次记录后再披露细节）：以 68 种组织、逾 1.07 亿单细胞谱训练，把非编码 DNA 变异的细胞类型效应预测做到 TenK10K 免疫数据集因果变异召回 30%（原版 16%），Francis Crick 研究所称其 30 分钟复现了团队一年半的湿实验；非商业研究免费。**AlphaProof Code**：多 LLM agent 框架生成逾 600 万行 Lean 证明，在编译机器码层面形式化验证 Signal 加密库的机密性、认证、前向保密与后泄露安全（未覆盖群聊与全部攻击面），并检出两处被重新注入的已知旧 bug；Anthropic 另称 1000 个 agent 用约 30 小时在 Lean 中形式化费马大定理（细节未充分公开）。东京大学团队并行定量超 3.9 万个天然蛋白变异/从头蛋白/纳米抗体的表达产量。AI4Science 的共同工程范式是：模型产出候选，由证明器或实验来否决错误答案。

### T11 · 英伟达权力交接与出口管制博弈
上周（11-13 期）晋升的线程本周密集演化：① 11-17 财季营收 1158 亿美元超预期，由临时 CEO Kress 主持，市场关注 700 亿美元初创投资、360 亿云算力担保、200 亿数据中心租赁如何执行；② 11-17 宣布停售 H200 至中国，结束此前需经美国境内并缴 25% 关税的出口通道；③ 董事会增设国家安全与出口管制监督委员会，合规与国安团队直接向 Kress 汇报；④ 黄仁勋 11-17 发声明承认个人生活严重错误、承诺配合独立调查，并称若董事会认为回归符合各方最佳利益「将荣幸回归」；特朗普公开表态希望由 Tim Cook「以传奇换传奇」接任；⑤ WSJ 报 SEC 就新加坡收入披露问题启动民事调查；⑥ 国会多方要求黄仁勋 12-01 闭门录证、12-03 公开作证、商务部长 12-10 约谈，众院中国特别委员会主席 Moolenaar 称其离任是「本可避免的结局」并促年底国防法案通过两党出口管制立法。

## B. 本周新热点（未入看板、有后续价值）

### B1. 微软 Ignite 2026 亮出 MAI 自研全栈，推出「可控权重」
- **时间**：2026-11-17（Microsoft Ignite 2026 主题演讲）
- **主体**：Microsoft、Microsoft AI（MAI）、Satya Nadella
- **事件**：MAI 一次性发布七款高性价比模型，其中 **MAI Code 2 / Code 2 Flash** 面向企业编码，四项基准平均达 GPT-6.1 Sol 98% 性能而成本仅 40%、达 Claude Opus 5.5 96% 性能而成本仅 5%，盲测前端评审 64% 胜过 GPT-6；**MAI Realtime 1** 为首个语音到语音模型、0.01 美元/分钟音频；并推出 **MAI Licensed Weights**，可定制后在自有 Azure 运行、自掌权重与数据。同期发布 Copilot 新形态、Microsoft IQ、Agent 365、Cobalt 200 VMs 等。
- **为什么值得关注**：这是最大「OpenAI 依赖方」首次把自研模型摆到与 OpenAI/Anthropic 同台竞价的位置，并用 Licensed Weights 把「模型可掌控性」做成卖点。它同时冲击编码模型价格带与企业采购逻辑，后续看 MAI 是否进入 Copilot 默认链路、Licensed Weights 的授权条款与生态采纳，故晋升为新看板线程 **T12**。

### B2. GPT-6.2 Astra / Sol 上线，系统卡把两项能力顶到 High / Critical
- **时间**：2026-11-17
- **主体**：OpenAI
- **事件**：发布面向复杂专业工作的 **GPT-6.2 Astra** 与面向日常 agent 工作的 **GPT-6.2 Sol**，同步上线 ChatGPT、Codex、API 与 OpenRouter、Perplexity、OpenClaw。定价 Astra 8/40、Sol 2/10 美元每百万 token；Artificial Analysis 智能指数升至第二、仅次 Claude Fable 5.2，Astra 每任务成本不到上代 GPT-6 Astra 三分之一（Perplexity WANDR：Astra 0.783、单任务约 12.54 美元）。系统卡按 Preparedness Framework 评定两模型 **生物化学 High、网络安全 Critical**，沿用 GPT-6 Astra 防护并加强研究环境安全与中央工作负载追踪。
- **为什么值得关注**：一边是「更快更省、指数逼近榜首」，一边是官方自评能力阈值再上台阶——能力曲线与安全阈值同步抬升，会让部署政策、访问分级（如 Mythos 5.2 的受限开放）成为常规动作。后续看阈值是否触发新的访问限制与监管问询。

### B3. 代理第一次真正握住支付与下单权限
- **时间**：2026-11-13（ChatGPT Wallet）
- **主体**：OpenAI、Google、Daydream
- **事件**：OpenAI 推出 **ChatGPT Wallet**，常驻代理 Dots 可为少数美国 Pro 用户购物结账，用户批准后以 token 替代银行卡号；Google 11-17 将 Gemini 任务功能免费开放六国数亿用户，可打电话预约、查账单、购物下单、接入 60 多款应用；购物代理 Daydream 能记住个人风格、虚拟试穿、按衣柜搭配、追踪折扣并完成购买。
- **为什么值得关注**：agent 从「生成建议」跨到「执行资金转移」，权限边界、授权可撤销性、争议责任与欺诈防护都成为新问题，且与 T1 的流量变现压缩直接相连。这是会持续演化的商业化—治理双线议题，故晋升为新看板线程 **T13**。

### B4. Microsoft 365 全球大宕机，暴露代理流水线单点依赖
- **时间**：2026-11-13
- **主体**：Microsoft
- **事件**：Microsoft 365 发生全球性中断，影响 74 个以上国家、约 700 万故障报告、持续近 20 小时，服务于 11-13 晚间恢复；微软归因于此前网络容量升级在近期网络变更后显现的问题，确认非网络攻击、非 AI agent 所致。
- **为什么值得关注**：并非 AI 事故，却是对 AI 基础设施的提醒——大量 agent 流水线把通信、文档访问与编排挂在单一供应商上，「一个收件箱、一个故障点」的集中度风险会在代理自动化放大下造成级联中断。后续看多云/多供应商容灾是否进入 agent 架构的常规要求（与 T7 供应链风险交叉）。

### B5. DeepMind：agent 集群把主流模型提示注入抵抗率打到 10% 以下
- **时间**：2026-11-09（arXiv 论文）
- **主体**：Google DeepMind（Alexey Kurakin 等）
- **事件**：论文《Scaling Adaptive Prompt Injection Attacks with Agent Swarms》用多个协作 agent 并行搜索注入载荷（共享策略数据库），以随机非恶意工具调用为目标以剥离「安全拒绝」干扰；在满查询预算下，7 个被测模型中 6 个抵抗率 ≤10%（Gemini 3.6/3.7/3.8 Flash、Kimi K3、GLM-5.3、DeepSeek-V4.1-Flash 多为 1%），仅 Gemini 4 Argon 保有 66%——它同时也是最强攻击者。作者强调：公开基准上的「稳健」可能是测量假象，前沿防御需主动自动化红队。
- **为什么值得关注**：这意味着「模型加固」不能单独作为防线，benchmark 成绩与真实弹性之间的差距会随攻击者工具升级而扩大；它与本周 Cursor、PyPI 两起真实供应链事故共同把 T3 从「模型安全」推向「全栈纵深防御」。

### B6. 「AI 泡沫本质是英伟达泡沫」：循环融资争议再起
- **时间**：2026-11-17
- **主体**：Ed Zitron（Where's Your Ed At）、巴克莱银行
- **事件**：Zitron 长文主张 AI 泡沫本质是 Nvidia 泡沫——通过循环融资、渠道压货与出口管制争议性交易维持增长机器，黄仁勋辞任后该模式难以为继；巴克莱报告亦指美国 AI 领域「供应商融资」与「循环投资」在产业起步期加速算力扩容的同时，模糊了真实终端需求边界，若财报不能打消资本开支放缓疑虑，硬件板块估值中枢恐进一步下修。
- **为什么值得关注**：这与本周 Nvidia 财报（数据中心占 93%）、对 Anthropic 等客户的股权与算力承诺、以及 SEC 披露调查互为印证，是判断算力景气真实性的关键争论。后续看关键客户资本开支指引、供应商业绩兑现与披露监管结论（与 T2/T7/T11 交叉）。
