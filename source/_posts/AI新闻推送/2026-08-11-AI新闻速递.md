## 1. 宇树科技科创板申购，A 股迎来"人形机器人第一股"

**事件**：宇树科技今日在科创板开启新股申购，上市市值约 **609 亿元**，中一签需缴款 7.54 万元，网上中签率仅 **0.0181%**，中签者账面浮盈有望超 30 万元。这是 A 股第一家真正意义上的人形机器人整机公司登陆资本市场。

**为什么值得关注**：具身智能过去两年一直在一级市场里"烧钱讲故事"，估值高但缺乏公开定价锚。宇树上市，等于把这条赛道第一次拉到了二级市场的显微镜下——季度财报、毛利率、出货量、研发费用率，全都要公开对账。0.0181% 的中签率说明市场情绪极度亢奋，但真正的考验在上市之后：**人形机器人能不能从"科技公司"变成"制造业公司"，靠的不是发布会，是良率和订单**。这家公司的股价曲线，未来会成为整个赛道最直观的体温计。

## 2. 中国厂商拿下全球人形机器人 97% 出货量

**事件**：彭博社数据显示，2026 年上半年全球人形机器人出货约 **1.91 万台**，其中中国制造商占比**超过 97%**。分厂商看，智元机器人出货 **8400 台**居首，宇树科技 **5900 台**紧随其后。人工智能、机器人、创新药构成的"新新三样"正成为中国外贸的新名片。

**为什么值得关注**：97% 这个数字要辩证地看。一方面，它确实反映了中国在供应链、执行器成本、整机集成上的碾压级优势——同样一台双足机器人，国内的物料成本可能只有海外的三分之一。另一方面，**出货量不等于使用量**。目前相当一部分订单流向的是高校实验室、展厅演示、租赁公司，而不是真正的生产工位。1.91 万台里有多少台在每天工作 8 小时？这才是决定 2027 年这个数字是继续翻倍还是掉头向下的关键。行业需要一个"人形机器人日均有效工时"的指标，而不是只看出货。

## 3. Docker 发布 Sandboxes：给自主编程 Agent 造一间"能砸的房子"

**事件**：Docker 正式推出 **Docker Sandboxes**，这是一种一次性的隔离执行环境，让 AI 编程 Agent 运行在独立的 **microVM** 内。在沙箱里，Agent 拥有完整的操作权限——可以安装软件包、运行嵌套的 Docker 容器、随意改动系统状态；但宿主机上只挂载当前活跃的项目工作区，其余文件系统完全不可见。用完即毁。

**为什么值得关注**：这条和昨天 Claude Code 默认开启自动模式是同一枚硬币的两面。当 AI 开始自己跑多步任务、不再逐条问你"要不要执行"，**"权限边界"就从 UI 层的确认弹窗，下沉到了基础设施层的隔离机制**。容器级隔离（namespace + cgroup）对付人类开发者的误操作够用，但对付一个会主动尝试各种命令的 Agent 就显得单薄了——microVM 提供的是硬件级虚拟化边界，逃逸成本高一个数量级。可以预见，"Agent 运行时"会成为独立的基础设施品类：沙箱、配额、审计日志、快照回滚，这套东西过去属于云厂商，现在要装进每个开发者的本地环境。

## 4. agent-skills 开源刷屏：给编程 Agent 补上"工程判断力"

**事件**：前 Google Chrome 团队成员、《Front-End Performance Checklist》作者 Addy Osmani 开源了 **agent-skills** 仓库，一天内冲上 GitHub Trending 榜首。该项目把生产级工程实践编码成可复用的"技能模块"：性能优化模式、无障碍合规（WCAG 2.2 AA）、安全审查流程、属性测试与混沌工程策略、架构决策框架等。每个技能模块包含决策树、检查清单和评估标准，并带有**显式触发条件**——当 Agent 遇到匹配的代码模式时自动检索并应用。仓库还附带评测框架，可以量化衡量 Agent 的工程判断力是否真的提升。

**为什么值得关注**：现在的编程 Agent 普遍存在一个尴尬：**语法正确率很高，工程判断力很低**。它能写出能跑的代码，但不会主动想"这个查询会不会 N+1"、"这个组件的 aria-label 呢"、"这段解析用户输入的代码要不要做长度限制"。agent-skills 的思路很务实——不靠把系统提示词写得更长，而是把专家经验拆成带触发条件的可检索模块，这本质上是**给 Agent 做 RAG，但检索的不是文档而是判断力**。它比"模型再大一点"更接近人类工程师成长的真实路径：靠积累模式和启发式，而不是靠背更多知识。唯一的隐忧是维护——最佳实践会过时，技能库需要社区持续更新。

## 5. 英伟达联合六大资管巨头，搭 5000 亿美元 AI 基础设施融资平台

**事件**：英伟达联合阿波罗、黑石、贝莱德、高盛、KKR 等六家资管巨头，宣布为 AI 数据中心与硬件采购搭建规模超 **5000 亿美元**的第三方融资平台。黄仁勋称，GPU 首次成为一类"可投资资产"（investable asset class）。此举被视为在全球市场 7 月大幅回调后，试图重振 AI 基础设施的资本信心。

**为什么值得关注**：把 GPU 变成"资产类别"，意味着算力的融资逻辑从"科技公司买设备"变成了"金融机构买租赁资产"——就像飞机、船舶、基站一样，可以做资产证券化、做经营性租赁、做残值担保。这对整个行业的影响是双向的：**好处**是中小 AI 公司不用一次性掏几十亿现金，租得起卡了；**风险**是 GPU 的技术折旧速度远快于飞机（三年一代架构），一旦下一代芯片能效跳变，前一代资产的残值会断崖式下跌，杠杆结构就会承压。这是 AI 基础设施第一次真正进入金融化阶段，值得长期盯着。
