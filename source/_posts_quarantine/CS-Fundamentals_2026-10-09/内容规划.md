## 四、各课模块拆分

### CS61B（数据结构与基本算法，Java）— 2024-09-30 起
1. 数据结构导论：ADT 与面向对象设计
2. 数组与动态数组（ArrayList）及均摊分析
3. 链表（单/双）与哨兵
4. 栈与队列
5. 树：BST、平衡树（AVL/红黑简介）、B 树
6. 哈希表：散列函数、冲突解决、扩容
7. 堆与优先队列（二叉堆）
8. 图：表示、DFS/BFS、Dijkstra
9. 并查集与排序（归并/快排/堆排）
10. 算法复杂度实战与收尾

### CS61C（计算机体系结构，可选）— 2024-11-04 起
1. 数字逻辑与 C 语言回顾
2. RISC-V 汇编基础
3. 过程调用与栈帧 / 调用约定
4. 组合/时序逻辑与流水线
5. 存储器层次与 cache
6. 虚拟内存
7. 并行与向量化（SIMD）
8. 中断与 I/O
9. 硬件/软件接口
10. 性能与 Amdahl 定律

### CSAPP / 15-213（计算机系统，硬核）— 2024-12-09 起
1. 信息表示：位、字节、整数与浮点
2. 机器级程序：汇编与栈帧
3. 缓冲区溢出与安全
4. 链接（Linking）
5. 处理器架构与流水线
6. 存储器层次与 cache
7. 虚拟内存
8. 系统级 I/O
9. 网络编程基础
10. 并发：线程与锁
11. 并发问题：死锁 / 竞争
12. 程序性能优化
13. 综合：一个 shell 与总结

### CS162（操作系统，必学）— 2025-01-23 起
1. OS 导论：抽象、机制、策略
2. 进程与线程
3. 调度算法
4. 地址空间与虚拟内存
5. 分页与 TLB
6. 文件系统接口与实现
7. I/O 与设备
8. 并发与锁
9. 条件变量与生产者-消费者
10. 死锁
11. 分布式入门 / RPC
12. 容错与日志
13. 总结：现代 OS

### CS186（数据库，重点 PostgreSQL）— 2025-03-10 起
1. 数据库导论与关系模型
2. 关系代数与 SQL
3. PostgreSQL 上手与数据类型
4. 索引：B+ 树 / 哈希
5. 查询处理与执行计划（EXPLAIN）
6. 查询优化器
7. 事务与 ACID
8. 并发控制：锁 / MVCC（PostgreSQL）
9. 故障恢复与日志（WAL）
10. 存储与物理设计
11. 进阶：JSONB / 扩展

### CS143（编译原理）— 2025-04-17 起
1. 编译器结构总览
2. 词法分析：正则与 DFA / tokenizer
3. 语法分析：CFG / parser
4. 递归下降 与 LR
5. 语义分析：作用域 / 类型
6. 中间表示 IR
7. 代码生成：IR → 汇编
8. 运行时系统：栈/堆/GC
9. 优化：数据流 / 公共子表达式
10. 进阶优化与寄存器分配

### CS194-196（AI Agent 研讨会 Seminar）— 2025-05-22 起
1. Agent 总览：从 LLM 到 Agent
2. 工具调用与 Function Calling
3. 规划与推理（ReAct / Plan-and-Execute）
4. 记忆（Memory）与上下文管理
5. 多智能体协作（Multi-Agent）
6. 检索增强 RAG 与 Agent
7. 评估与安全 / 对齐
8. 前沿论文串讲与总结

### CS229（古典机器学习，可选）— 2025-06-19 起
1. 监督学习导论与线性回归
2. 逻辑回归与分类
3. 梯度下降与凸优化基础
4. 过拟合与正则化 / 偏差方差
5. 神经网络与 BP（古典）
6. SVM 与核方法
7. 无监督：k-means / PCA
8. EM 与高斯混合
9. 模型选择与评估

### DeepLearning（经典深度学习，可选，非强制）— 2025-07-21 起
1. 前馈神经网络与反向传播
2. 激活/初始化/优化器
3. CNN 卷积神经网络
4. RNN / LSTM / 序列建模
5. Word2vec 与词嵌入
6. Seq2Seq 与注意力机制（Attention）
7. Transformer 架构
8. 训练技巧与正则化（Dropout / BatchNorm）
9. 落地：部署与工程实践
